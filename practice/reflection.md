# Git workflow reflection

Write at least one complete sentence for each answer. Each answer must contain at least 20 characters.

## 1. What is the difference between a commit and a push?

Answer: Commit saves the changes to Git, while push uploads the commits so that other people can see them.

## 2. Why work on a branch instead of directly on `main`?

Answer: Working on branch allows you to make changes without affecting the main branch.

## 3. What does a pull request make possible?

Answer: It allows other people to see the changes before merging it to the main branch.

## 4. Which Git command helped you understand the repository's state, and what did it show you?

Answer: The command helped me see which branch I was on and which files have been edited.
